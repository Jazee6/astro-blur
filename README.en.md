# Astro Blur

A static Astro blog theme

[中文](./README.md) | English

![Theme Preview](https://blog-cdn.jaze.top/2024/07/6e7813e44dad9a35be6c42b2c2e4eb53.webp)

## Features

- ✅ 100% native components, pure static generation
- ✅ Twikoo comment system
- ✅ SEO friendly — OpenGraph / Sitemap / RSS
- ✅ Responsive layout / code highlight / Mermaid diagrams / theme switch

## Quick Start

```shell
# Download template
npx degit Jazee6/astro-blur#main my-blog

# Enter project
cd my-blog

# Install dependencies (building Mermaid diagrams requires Microsoft Edge)
bun install

# Start project
bun run dev

# Create new post
bun run new

# Config modify
./src/config.ts
```
